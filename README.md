# RecoFi

カードなどで支払ったその場で、実際の購入内容を素早く記録し、カード明細との照合まで行えるAndroid家計簿アプリです。

## 主な機能

### 明細管理

- 支払方法を切り替えながら、項目・利用日・金額・取引先・内容を記録
- 月別の利用額、未確認明細、固定費由来の明細を一覧表示
- 明細の編集・削除と、削除前の確認ダイアログ
- 金額入力に数字キーボードを使用
- 項目、よく使う取引先、よく使う内容による入力補助
- 過去の取引先・内容と項目を使った端末内の項目候補

### カード明細の照合

- 楽天カードとビューカードのPDF／CSV明細に対応
- ファイル内の日付・金額・利用店名を使った自動照合
- 入力漏れを推測明細として追加し、未確認状態で表示
- 同一ファイル・同一内容の重複取込を防止
- 支払方法・月ごとに取込ファイルを1件だけ紐づけ
- 設定画面から取込ファイル名、対象月、件数、紐づけ先を確認・削除
- 消込が完了した月を確定し、手動・自動の再消込をロック

### 予算と分析

- 毎月共通の予算と、月ごとの個別予算を設定
- 現在の支出と予算比を円グラフで可視化
- 項目別支出と固定費を円グラフで分析
- 日ごとの支出額をカレンダーで可視化し、日付から明細を確認
- 取引先別ランキングと利用傾向のまとめ
- 分析結果の項目をタップして対象明細を表示

### 固定費

- 金額、項目、請求日、契約日、取引先、内容を登録
- 1か月単位で任意の支払い間隔を設定
- 契約日以降の該当月へ固定費明細を自動登録
- 料金改定日以降の金額変更と契約終了日の管理
- 終了した固定費のアーカイブ、編集、複製、削除

### 設定とデータ

- 支払方法、支出カテゴリ、共通の取引先・内容テンプレートを管理
- カテゴリ、取引先、内容テンプレートを並べ替え（各15件まで）
- 月・支払方法を指定したCSVエクスポート
- データはオフラインで端末内に保存

## 開発環境

- Kotlin
- Jetpack Compose
- Android SDK 36
- Android 8.0（API 26）以上

## 開き方

1. Android Studioでこのフォルダを開きます。
2. Android Studio付属のJDKとAndroid SDK 36を選択します。
3. Gradle Syncを実行します。
4. Android 8.0（API 26）以上の端末またはエミュレーターで実行します。

初回のGradle Syncでは、Android公式リポジトリから依存関係を取得するためインターネット接続が必要です。

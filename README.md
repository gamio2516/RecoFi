# RecoFi

カードを使ったその場で、実際の購入内容を素早く記録するAndroid家計簿アプリです。

## 主な機能

- 支払方法ごとの明細記録・確認
- 項目、利用日、金額、備考の登録と編集
- 月別利用額と予算の比較
- 項目別・固定費・備考別の支出分析
- 過去の備考から項目候補を出す端末内AI
- 項目と支払方法別の備考設定
- 月次から2年ごとまで対応する固定費の自動登録
- 固定費の料金改定、契約終了、アーカイブ、複製
- オフラインでの端末内保存

## 開発環境

- Kotlin
- Jetpack Compose
- Android SDK 36
- Android 8.0（API 26）以上

## 開き方

1. Android Studioでこのフォルダを開きます。
2. Android Studio付属のJDKとAndroid SDK 36を選択します。
3. Gradle Syncを実行します。
4. Android 8.0（API 26）以上の端末またはエミュレーターで実行します。

初回のGradle Syncでは、Android公式リポジトリから依存関係を取得するためインターネット接続が必要です。
